# react-native-pixelkit

A simple pixel UI library

## Installation


```sh
npm install react-native-pixelkit
```


## Usage


```js
import { PixelBox } from 'react-native-pixelkit';

// ...

<PixelBox options={{ backgroundColor: '#4caf50', bevel: true }}>
  <Text>Hello</Text>
</PixelBox>;
```
